## GOLD JSON 정리 + 재벤치마크 (23:10 완료)

### 변경 사항

- GOLD JSON 내 ConceptSet name에서 `[TROY]` / `[TROY condition]` 접두사 44건 제거
- 오타 수정: `Revasculariazation_final` → `Revascularization`, `proteimuria` → `proteinuria`
- 파일명 정리: `[TROY] Liraglutide (LEADER) GOLD.json` → `LEADER_GOLD.json`
- SQL 파일도 `data/gold/LEADER/`로 통합 (`LEADER_GOLD_v1.sql`, `LEADER_GOLD_v2.sql`)
- 정리된 JSON으로 A_direct v3 (C) 재실행

### 결과

- **정리 후**: Avg R=75.0%, P=56.6%, F1=53.5%
- **정리 전**: Avg R=80.4%, P=50.4%, F1=50.2%
- ΔR=-5.4pp, ΔP=+6.2pp, ΔF1=+3.3pp
- Full: 12→11, Wrong: 2→3
- **정리 후(75.0%)가 진짜 성능** — 이전 수치는 `[TROY]` 접두사가 Agent2 query에 포함되어 인위적으로 부풀려진 것

### ⏱ 실행 시간

- 벤치마크 ~5분

### 💡 인사이트

- ConceptSet name이 Agent2의 query text로 사용되므로 이름 변경이 직접 성능에 영향
- `[TROY]` 접두사가 벡터 검색에 노이즈로 작용 → Recall 부풀림 유발
- 평가용 reference JSON은 반드시 clean name으로 관리해야 재현 가능한 벤치마크 확보

## Exp D: 원문(NCT+PDF) → Agent1 → Agent2 with GOLD (23:40 완료)

### 변경 사항

- `benchmark_exp_d.py --troy data/gold/LEADER/LEADER_GOLD.json` 실행
- NCT01179048 JSON + NEJMoa1603827 논문(본문+Appendix) → Agent1 → Agent2 → GOLD 비교

### 결과

- **Exp D (원문)**: Avg R=58.4%, P=28.3%, F1=32.9%
- vs A_direct (CS이름): R=75.0%, P=56.6%, F1=53.5%
- Full(≥80%): 5 | Partial(30-80%): 6 | Wrong(<30%): 4 | Empty: 2
- Empty: `No acute decompensation`, `No drug use or dependence` — Agent1 미생성
- No pregnant 3%: Agent1 과도 분해 (8개 sub-rule)
- No malignant 95%: 원문에서도 높은 매핑

### ⏱ 실행 시간

- ~10분 (Agent1 PDF 파싱 포함)

### 💡 인사이트

- Agent1 Exclusion polarity 손실이 핵심 병목: 15개 exclusion 중 14개를 PRESENCE로 출력
- `No drug use`, `No pregnant`는 원문 미명시(TROY 추가) → 평가 제외 대상
- 상세: [EXP_D_VS_A_DIRECT_GAP_ANALYSIS.md](./experiments/EXP_D_VS_A_DIRECT_GAP_ANALYSIS.md)
